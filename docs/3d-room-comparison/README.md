# A2 机房全室精修交付记录

日期：2026-11-02。[拖动查看前后对比](index.html)。本轮基线是上一阶段已完成基础校准、R04 精修的版本；没有把原始未校准版本作为本轮性能基线。

## 实现范围

- 所有 14 座 42U 机柜采用一致的喷涂钢板、窄倒角、前门框/穿孔门、独立铰链和把手、铭牌、导轨与 U 位刻度、后部双门/通风面、双 PDU 结构。未纳管机柜保持未纳管状态，没有伪造设备。
- 全部 26 台设备增加可拾取的托盘、拉手、固定耳/紧固件或网络端口；保持原设备 ID、父机柜、U 位和告警口径。设备外壳无自发光，LED 按设备状态显示。
- 完整冷通道增加两端滑门结构与标识、连续送风地板、桥架/线束、维护区地面边界；房间墙板、铭牌、灯具、空调门缝/把手/底座使用统一材质。端门以开启停靠位置展示。
- 总览、全室与近看采用顶部剖切，隐藏顶盖和悬吊灯具以便查看设备；通道视角保留它们。这是可视化剖切，并非所有灯具消失的实际建筑状态。
- 总览 / 通道 / 全室 / 任意机柜近看四种视角；近看自动匹配 A/B 排方向并隐藏对侧机柜。14 个柜门状态独立保存，工具栏操作当前选中机柜。机柜标签支持鼠标和键盘选择，HUD 保留设备入口、预警和 U 位跳转。
- `dc3d-policy.js` 抽出有回归覆盖的拾取、视角与细节距离规则。透明门后的拾取仅允许同柜设备；隐藏机柜不会抢占命中。

## 性能实现

- Blender 导出时按父级/材质/设备合并装饰件，并共享完全一致的网格数据；所有纹理内嵌，无新增第三方请求。
- 设备面板基础结构与 LED 始终存在；小型机械件和详细设备部件在 5.5 m 内显示、6.5 m 外隐藏，使用滞回避免在临界距离反复跳变。近看的目标柜保留全部细节。
- 静态阴影缓存仅在剖切/场景显隐改变后重绘。细微零件不投影；机箱、框架与场景仍有接触阴影。
- 中性材质共享，只对悬停表面与设备 LED 复制可变材质；环境 RenderTarget 在主题切换时复用。
- 网孔贴图校正横纵重复率，使用 MSAA alpha-to-coverage 和各向异性过滤，减轻近看拉伸及远处锯齿。
- 保留按需渲染与隐藏视图暂停，恢复固定镜头会清除旋转阻尼。

## 同机性能实测

Windows 本机，系统报告 CPU 为 Intel Core Ultra 5 228V、物理 GPU 为 Intel Arc 130V；系统还安装了虚拟显示适配器，未据此推定浏览器实际使用的 GPU 后端。浏览器为 Chrome 156，页面 1280×720，画布 CSS 1108×443，DPR 1。

两版使用同一 `scene-benchmark.js`、同样的总览/通道/R04 镜头、相同 FOV 与连续轨道旋转。每镜头预热 30 帧、记录 240 帧，共 720 帧约 13.5 秒。绘制调用计入完整场景、阴影和后处理；CPU 时间包括布局/控制器/LOD/标签与 compositor 的提交过程。CPU 提交耗时不是 GPU 执行时间；帧间隔受显示器/调度影响，不是跨硬件帧率保证。

| 镜头 | 绘制调用中位数 前→后 | CPU 提交 P95 前→后 | 帧间隔中位数 前→后 | 帧间隔 P95 前→后 |
| --- | ---: | ---: | ---: | ---: |
| 机柜区总览 | 392 → 293 | 6.6 → 4.1 ms | 16.7 → 16.7 ms | 19.5 → 19.1 ms |
| 通道 | 386 → 421 | 6.3 → 4.9 ms | 16.7 → 16.6 ms | 21.5 → 19.5 ms |
| R04 近看 | 296 → 324 | 5.6 → 3.9 ms | 16.8 → 16.7 ms | 28.2 → 18.8 ms |

总览绘制调用减少约 25%；通道和机柜近景因全量精修增加绘制调用，CPU 提交 P95 仍低于本轮基线。三种镜头的实测 P95 CPU 提交均低于 5 ms，最大绘制调用不超过 422。原始数据：[改造前](performance-before.json)、[改造后](performance-after.json)。这是一台机器的短时交互验证，没有覆盖长时间温控降频、4K/DPR 2 或其他 GPU。
