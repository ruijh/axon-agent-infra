# 跨层拓扑 3D 改造与验证

验证日期：2026-11-02。截图来自运行中的应用，不是设计稿。打开 [前后对比](index.html)，或进入应用 `/?topo=overview`、`/?topo=agent`、`/?topo=impact`。

## 已实现

- 固定像素的 DOM 标签，保留完整对象 ID；完整名称可通过悬停、搜索及详情读取。屏幕空间避让，优先保留根节点和当前选择。默认 1280×720 窗口全图显示 52 个标签。
- 正交相机、有限的环绕角度、按范围适配镜头；搜索聚焦、Home 恢复镜头、重置布局与分析。程序化镜头切换先清除残余阻尼，避免快速拖拽后复位漂移。
- 统一 2D／3D 的选择、故障源、分析范围和推断过滤。空白点击与 Esc 清除，原有对象详情及业务操作入口保留。
- 依赖方向是使用方 → 资源；故障传播方向是故障源 → 使用方。静态箭头始终存在，方向动画由用户开启且遵守减少动态效果偏好。
- 任意节点都可进入完整依赖或影响推演。分析采用完整的有向可达闭包；循环、共享资源、重复路径和悬空关系不会造成错误计数。推断关系可排除；仅经推断才能到达的对象单独计数。
- 节点及箭头实例化，连线按样式合批，共享几何和材质；文字不再逐节点占用 CanvasTexture。静止、隐藏或切换到其他视图时停止 3D 重绘。

`node --test tests/*.test.mjs`：**52 / 52 通过**，其中新增 12 项拓扑测试。日志：[tests.txt](tests.txt)。

新增测试覆盖：有向闭包、反向影响、根节点与连线、循环及多路径、推断过滤、Agent 共享资源隔离、真实样板计数、选择与分析源分离、清除与重置、对象移除、全 52 个节点的两类分析及布局、标签避让、资产编号搜索、真实 OrbitControls 的残余阻尼复位。

浏览器实测：

- 搜索 `AST-10243` 定位 CPU-01，镜头 zoom=1.65；Esc / 空白点击清除；重置回到 zoom=1、position≈[55,105,1500]、target=[0,0,0]。
- 鼠标环绕不丢失分析范围；快速拖拽后立即 Home 恢复准确姿态。
- 故障推演中选中 ERP 任务，2D → 3D 保留任务选择和 CPU-01 故障源；推断过滤更新边数。
- 方向演示开启后帧计数增长，关闭后回到按需绘制。
- 静止帧计数 15 → 15；切换到总览期间帧计数 50 → 50。
- 8 轮切换，每轮两次主题、三次范围、两次 2D／3D，逐轮验证 15 → 27 → 52 个对象。回到全图纹理 / 几何体 / 程序稳定为 1 / 5 / 4。
- 浅色和深色标签可读，无浏览器控制台错误。修正主题通知遮挡顶部控制按钮的问题。

复测入口：`/?topo=overview&topoDiagnostics=1`，点击“运行拓扑基准”；追加 `&topoBenchSize=1` 固定画布为受控尺寸。诊断面板仅在显式参数存在时加载到界面。
