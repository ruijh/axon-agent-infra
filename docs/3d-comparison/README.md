# 3D 基础校准与精修样板交付记录

日期：2026-11-02。对比入口：[交互对比](index.html)。截图为浏览器实际 WebGL 画面，没有生成式图片或后期修饰。

## 已实现

- `assets/dc3d.js`：中性灯光、低强度 Bloom、外壳零自发光；总览/通道/R04 三个固定视角，默认不旋转。R04 剖切视角隐藏对侧机柜和顶盖，柜门可以开合。
- 机柜编号改成 DOM 标签，避开辉光与色调映射；告警由文字与 LED 表达。物理材质不随八套 UI 主题换色。
- `assets/env3d.js`：每个场景保有一个 PMREM RenderTarget，主题切换复用；释放时 dispose 整个目标。机房与拓扑均增加页面退出时的资源释放。
- 机房采用按需渲染；移除机房和拓扑的定时器补帧。拓扑关闭默认旋转，降低发光，修正文字被卡片遮挡的问题，粒子仅在聚焦路径上出现。
- `assets/data.js` 与 `tools/export-layout.mjs`：机柜尺寸和 X 坐标写入共享布局；演示机柜中心间距 0.68 m，净距 0.06 m，冷通道净宽 1.64 m。二维展开图保持可读的非等比例示意，并显示实际尺寸。没有改动控制平面数据库。
- `tools/build_dc_model.py`：空调改用父对象局部坐标，导出前检查房间边界；R04 增加窄倒角、门框、铰链、穿孔门、导轨刻度、盲板、盘托、拉手、网络接口和紧固件。设备继续按数据中的 U 位放置，所有可点部件携带原设备 ID。
- 通道增加穿孔送风地板、桥架横档、顶灯和标识。喷涂表面与穿孔面包含法线、粗糙度/金属度/AO 数据，细孔用贴图表达。
- 导出前按父对象、材质、设备及 LED 类型合并装饰部件；柜门铰链、设备身份和透明顶盖保留独立控制。

## 截图条件

- 浏览器默认视口 1280×720，画布布局尺寸一致，默认深空靛蓝主题，FOV 46°。
- R04：相机初始位置 `[0.65, 1.5, -0.75]`，目标 `[0, 1.04, 2.55]`。两版使用相同 OrbitControls 极角限制，因此实际相机位置均由同样的限制修正。两版均隐藏 B 排及顶盖；新版柜门打开。
- 通道：相机 `[-4.2, 1.65, 1.2]`，目标 `[0.4, 1.15, 1.2]`。
- 原版基线仅关闭自动旋转，加入相同相机参数、剖切范围和响应式画布高度；保留原版 GLB、材质、灯光和 Bloom。布局变化是真实实现差异。
- `after-overview.jpg` 为新版总览镜头，不作为相同镜头对比。

## 范围与后续

本轮精修集中于 R04 及通道，其余机柜只做基础材质、倒角、盲板与布局校准；服务器面板为结构示意，并非对应厂商的精确 CAD。尚未实施整室资产精修、高低模烘焙、LOD、纹理压缩，以及拓扑全量标签碰撞/聚合设计。没有进行指定 GPU 的长时间帧率测试。

本地查看：启动 `python _serve.py`，进入「服务器 → 3D 机房 → R04 精修样板」。可在 URL 添加 `?dcCamera=rack` 或 `?dcCamera=aisle` 预设镜头；`&diagnostics=1` 为显式开发诊断模式，正常入口不显示技术统计。
