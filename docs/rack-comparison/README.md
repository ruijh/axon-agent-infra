# 机柜标签、布局与交互验证 · 2026-11-06

## 实施范围

- `rack-layout.js` 统一 42U 的几何计算：26px/U 标准、30px/U 详情；1U 单行、2U 及以上双行。设备位置、机柜总高、背景网格与刻度同步，无跨 U 位扩高。
- 共享机柜宽 320px，窄屏按容器收缩并只显示当前机柜；独立刻度区，名称省略时可通过按钮详情获得完整内容。
- 平面图保持可读最小宽度，在地图容器内滚动；机柜选择、SVG Enter/空格和 U 位详情同步。
- 服务器保留原资产抽屉；网络设备从短暂 Toast 改为持久详情抽屉。机柜、平面、网络和 3D 通过共享入口定位对应机柜。
- 抽屉关闭时 inert，打开/关闭恢复焦点；确认弹窗接管焦点，Escape 只关闭顶层。
- 网络拓扑增加机柜范围和完整设备清单；全图内部滚动，单柜重新排布，点击使用实际事件坐标。原链路与端口映射保留。
- 3D 标签缓存实测尺寸，避让工具栏、HUD、图例与其他标签；选中和预警优先。手机视口下 HUD 移到画布下方。
- 新增运行时模块已纳入两种服务器共用的静态资源白名单。
